// JS behavior
JS is an asynchronous language, but its default behavior is synchronous. We have to force that behavior to be async. T
he easiest example is your setTimeout or setInterval methods.

// synchronous
Synchronous (Blocking) Code: Code executes line by line. 
If one task takes time (e.g., fetching data from an API), the entire browser freezes until it completes.
